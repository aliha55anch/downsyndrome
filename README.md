# Little Steps

Little Steps is a Laravel 12 application for learning activities, family progress tracking, professional profiles, and appointment booking.

The Laravel application is in `app/`, `routes/`, `resources/`, and `database/`. Static public pages and assets are in `public/`. See [PROJECT_MANUAL.md](PROJECT_MANUAL.md) for complete setup, usage, testing, and handover instructions. A DOCX copy is available separately.
